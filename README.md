 - '<!DOCTYPE html'> - declaramos el tipo de documento ,este uerfano indica al navegador que el documento con en el que se edta trabajando
y que debera realizar es 'html' , **siempre debe estar en la primera linea**.
 -'<head></head>' - elemento raiz devuelve todo el contenido de la pagina html , ete elemento tiene dos hijos principales.

 - <head></head> - elemento de configuracion, contiene informacion imprtante sobre el documento como ( titulo, enlases css, infotmacion para motores de busqueda, descripcion entre otros)
 - '<title></title>' - elemento de titulo de pagina, es el hijo de 'head' y define el titulo que aparecera en la pestaña del 
navegador.
